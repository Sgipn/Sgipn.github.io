Neuroscience · NLP

Language to Brain Signal Analysis

Understanding how the brain represents language could inform brain-computer interfaces and reveal whether today's AI language models actually mirror human cognition. Compared word-embedding strategies against fMRI brain activity recorded while subjects listened to natural speech, to identify which linguistic representations the brain actually computes. Contextual BERT embeddings predicted neural response better than static embeddings, grounding modern language models in real brain data.

  • Evaluated a progression of embeddings (Bag-of-Words, Word2Vec, GloVe, a custom BERT-style encoder, pretrained BERT) against voxel-wise fMRI BOLD signals using ridge regression.
  • Trained a custom encoder from scratch with masked language modeling and Optuna hyperparameter tuning, then adapted a pretrained BERT to narrative text with LoRA fine-tuning.
  • Validated findings across two subjects and used SHAP/LIME to identify which words drove predictions in the best-predicted brain regions.

Languages: Python

Frameworks: PyTorch, Hugging Face Transformers, LoRA/PEFT, scikit-learn, SHAP, LIME, Optuna

AI Agent · Text-to-SQL

Text-to-SQL Agent for Revenue and Churn Analytics

SQL fluency shouldn't be a prerequisite for getting answers from data, yet it remains the biggest bottleneck between a business question and a business insight. Converts plain-English business questions into validated SQL, letting stakeholders self-serve revenue and churn metrics without waiting on an analyst. Two independent safety layers keep every generated query read-only and schema-approved.

  • Enforced two-layer safety: AST parsing via sqlglot restricts queries to SELECT-only on approved views, backed by read-only DuckDB execution as a failsafe.
  • Computed ratio metrics like ARM and churn rate dynamically using Delta Method confidence intervals validated through Monte Carlo simulation.
  • Used ChromaDB semantic retrieval over approved metric/schema definitions so the agent declines undefined-metric questions instead of hallucinating.

Languages: Python

Frameworks: DuckDB, dbt / MetricFlow, ChromaDB, sqlglot, Anthropic Claude API

Optimization · Fraud Detection

Efficient Hyperparameter Tuning Using Bayesian Optimization for Credit Fraud Detection Applications

Fraud detection models are notoriously expensive to tune, and every wasted hyperparameter search delays catching fraud that costs real money. Applied Gaussian Process-based Bayesian Optimization to tune LightGBM for imbalanced fraud detection, validated on classic benchmark functions before deployment. Reached stronger Average Precision with far fewer model evaluations than a grid search would need.

  • Implemented a GP surrogate with a Matérn kernel and compared Expected Improvement vs. Lower Confidence Bound acquisition functions for sample-efficient search.
  • Validated convergence behavior on benchmark functions (Branin, Hartmann-3) before applying the same pipeline to the IEEE-CIS fraud dataset.
  • Tuned LightGBM under stratified 5-fold cross-validation, optimizing for Average Precision on highly imbalanced fraud labels.

Languages: Python

Frameworks: LightGBM, scikit-learn, Gaussian Processes
