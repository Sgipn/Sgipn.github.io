AI Agent · Text-to-SQL

Text-to-SQL Agent for Revenue and Churn Analytics (2026)

SQL fluency shouldn't be a prerequisite for getting answers from data, yet it remains the biggest bottleneck between a business question and a business insight. Converts plain-English business questions into validated SQL, letting stakeholders self-serve revenue and churn metrics without waiting on an analyst. Two independent safety layers keep every generated query read-only and schema-approved.

  • Engineered an end-to-end agentic Text-to-SQL system using LangChain and LLM reasoning workflows to convert natural-language queries into executable, optimized SQL.
  • Enforced two-layer safety: AST parsing via sqlglot restricts queries to SELECT-only on approved views, backed by read-only DuckDB execution as a failsafe.
  • Implemented automated error-handling and self-correction loops so invalid or failing SQL is automatically retried and repaired before being surfaced to the user.
  • Computed ratio metrics like ARM and churn rate dynamically using Delta Method confidence intervals validated through Monte Carlo simulation.
  • Used ChromaDB semantic retrieval over approved metric/schema definitions so the agent declines undefined-metric questions instead of hallucinating.

Languages: Python

Frameworks: LangChain, DuckDB, dbt / MetricFlow, ChromaDB, sqlglot, Anthropic Claude API

Understanding how the brain represents language could inform brain-computer interfaces and reveal whether today's AI language models actually mirror human cognition. Built a voxel-wise ridge regression pipeline across ~190K voxels (2 subjects, 101 stories) comparing six embedding strategies: static and custom-trained embeddings carried near-zero signal (mean correlation ≈ 0.01), while pretrained BERT embeddings improved correlation by ~80%.

  • Designed a 6-way comparative study (Bag-of-Words, Word2Vec, GloVe, a custom-trained BERT-style encoder, pretrained BERT, and a LoRA fine-tuned BERT) to identify which representation best predicts brain activity during natural story listening.
  • Ran per-voxel grid search and cross-validation across ~190K voxels; static and custom embeddings carried near-zero signal (mean CC ≈ 0.01) while pretrained BERT gave ~+80% in correlation.
  • Fine-tuned bert-base-uncased with PEFT/LoRA in PyTorch (Optuna hyperparameter search), finding only marginal, inconsistent gains over the base pretrained model.
  • Applied SHAP and LIME to the best-predicted voxels to surface interpretable word-level drivers of brain activation.

Geospatial Analysis

Polar Cloud Detection using Geospatial Satellite Imagery (2024)

Cloud cover commonly distorts satellite-based climate measurements, which makes cloud detection in polar regions especially difficult since snow and ice visually mimic clouds. Moreover, expert labels are scarce: only 3 of the 164 MISR images used here are labeled, further adding to the difficulty of analysis common amongst remote sensing ML applications. This project tackles the problem of detecting cloud cover in polar regions given the lack of labeled data and the risk of spatial autocorrelation inflating validation performance.

  • Pre-trained multi-layer neural network autoencoders on unlabeled multi-angle MISR imagery (source: NASA) via transfer learning, extracting 40-dimensional latent embeddings across spatial 3x3 to 9x9 neighbor windows.
  • Classified cloud cover and terrain by training LightGBM, Random Forest, and k-NN models on the resulting multi-angular spatial features, reaching 98.74% classification accuracy on unstructured imagery.
  • Ran quadrant-based spatial cross-validation and perturbation/noise-injection stress testing to evaluate model stability and out-of-distribution generalization.

Languages: Python

Frameworks: TensorFlow / Keras, scikit-learn, LightGBM
